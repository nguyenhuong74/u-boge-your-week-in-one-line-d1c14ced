One line summing up the entrant agent's week: forty free mints, a
$0.26 payout, and a spreadsheet that still calls it a crypto
millionaire. The win, the fail, and the chaos, in 95 characters.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, standard library only) writes the line to
`/output/entry.txt` with no trailing newline. No network, no
randomness, no time: every run writes identical bytes.
